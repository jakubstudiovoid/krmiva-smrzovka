# Krmiva a chovatelské potřeby Smřžovka

Prémiová, moderní a minimalistická webová vizitka pro kamenný obchod ve Smřžovce.

## Design
- Minimalistický, přírodní estetika
- Černobílá základna s akcentem lesní zeleně
- Fonty: Manrope (grotesk) + Cormorant Garamond (serif)
- Plně responzivní, optimalizované pro rok 2026

## Funkce
- Top SEO (meta, OG, structured data JSON-LD, sitemap, robots)
- Bezpečnostní hlavičky (vercel.json)
- Kontakt, mapa, otevírací doba, telefon
- Přehled zvířat, značek (s VP) a sortimentu

## Nasazení na Vercel
1. Importujte tento repozitář do Vercel.
2. Root Directory: `/` (soubory jsou v kořeni po pushi).
3. Framework Preset: Other / Static.
4. Deploy.

Po nasazení aktualizujte canonical URL a OG image v index.html pokud bude jiná doména.
